# Анимированные эффекты навыков (Skill FX)

Каждый навык имеет собственный эффект: модель GeckoLib + набор анимаций (`in` — появление, `loop` — цикл, `out` — исчезновение, `hidden`) + цветовая тема.
Всё строится процедурно скриптами `tools/fx_models_a.py`, `tools/fx_models_b.py` (через `tools/fxkit.py`); `python3 tools/gen_assets.py` запускает всё сразу
(`tools/gen_fx.py` пишет 28 моделей, анимации и 12 текстур-тем, проверяет кости и порядок ключевых кадров). Предпросмотр: `python3 tools/fx_preview.py out.png sculk_tentacle ...`.

## 2D-спрайтовые эффекты (0.6, Магоборец)
Те же приёмы, что у волны/водоворота Вод Подземного Мира: **плоские тонкие панели** (толщина 0,5 пикселя модели) с нарисованным спрайтом, анимация — вращение, масштаб и **покадровое переключение** (кадры — отдельные панели, видна одна за раз). Генератор: `tools/fx_sprites.py` (рисует листы 128×128 и собирает модели/анимации); тип в `FxType` с последним аргументом `sprite` (1 — один лист `spr_<id>.png`, n > 1 — n вариантов листа по значению `theme`, напр. тентакли за спиной: 3 / 5 / 1 щупальце). Тексель (127,127) каждого листа прозрачен — его берут тонкие рёбра панелей. Скрещённые панели видны со всех сторон; лучи (`beam`) — звезда из трёх панелей, повёрнутых вокруг оси луча, зеркальный участок листа для западной грани.

## Как это устроено
- **Сущность `SkillFxEntity`** (одна на все эффекты): тип и тема синхронизируются, режимы на сервере — на месте, следовать за сущностью, **луч** между двумя сущностями (отслеживает обе каждый тик, растягивается по длине, вытягивается/втягивается за 4 тика), **снаряд** (летит из A в B).
- **Рендерер** сам применяет рысканье/тангаж/крен (GeckoLib этого не делает для не-живых сущностей), свечение (`entityTranslucentEmissive`), отложенный старт (`delay`).
- **Анимации не зависят от знаков осей**: вращения/позиции симметричны, поэтому эффекты выглядят верно при любом соглашении о знаке в загрузчике; тонкие повёрнутые панели намеренно не используются.
- **Темы** (`Fx.SCULK … Fx.STEEL`): палитра из 8 ячеек (ядро, тело с жилами, тёмная, акцент, пламя/градиент, грани, кость, глаз) — одна модель, разные цвета.

## Как добавить эффект
(2D-спрайт: функции `tex_<id>()` и `model_<id>()` в `tools/fx_sprites.py`, имя в `SPRITES`, тип в `FxType` с аргументом `sprite`.)
1. Постройте модель в `tools/fx_models_*.py` (функция возвращает `(M, finish(...))`) и добавьте имя в `FX_NAMES` (`tools/gen_fx.py`).
2. Добавьте константу в `fx/FxType.java` (`beam=true` для растягиваемых между двумя точками).
3. Вызовите `Fx.at / follow / beam / bolt` из навыка (см. `DkAbilities`, `SpiritAbilities`); `python3 tools/validate.py` сверит имена, файлы и анимации.
Ограничения: оружейные/позовые анимации самого игрока не меняются (ванильный взмах); для них нужен Epic Fight / PlayerAnimator.

## Текстуры (обновление 0.4.1)
- **Атласы 128×128** на тему (`textures/entity/fx/theme_N.png`): 16 тайлов 32×32 — свечение, поверхность (A/B/…): `A` glow, `B` поверхность, `C` тёмная, `D` узлы, `E` пламя, `F` кристалл, `G` кость, `H` глаз, `I` прожилки, `J` перепонка, `K` энергия, `L` искры, `M` рунный камень, `N` шип, `O` поверхность-2, `P` точки.
  Тайлы генерирует `tools/fxtex.py` (шум, ячейки Вороного, случайные ходы для жил) — не плоские цвета.
- **Скалк (темы 0, 9 «золотой», 10 «глубокая тьма»)** — в стиле скалка Майнкрафта: очень тёмная сине-бирюзовая «влажная» ткань, более светлые бугристые пятна, светящиеся голубые узелки с тёмным ореолом, тонкие светящиеся прожилки, кость-«шрайкер» для когтей. Иконки навыков/талантов пути скалка нарисованы на той же текстуре.
- **UV с постоянной плотностью**: каждая грань берёт участок тайла, размер которого пропорционален размеру грани (`dens` текселей на пиксель модели), со случайным смещением — соседние кубы не повторяют один и тот же фрагмент, текстура не растягивается.
- **Свет и тени**: твёрдые эффекты (щупальце, рука, цепь, шипы, кокон, ковёр скалка) рендерятся с нормальным затенением граней (`entityTranslucent`), светящиеся (кольца, пламя, призраки) — без освещения (`...Emissive`). Флаг `emissive` в `FxType`.
- **Геометрия без «сетки»**: кольца и купол собраны из сплошных, стыкующихся блоков (без просветов); аура скалка — «ковёр» из пятен скалка с узелками и стебельками-датчиками, который растёт от центра (анимация появления) и сворачивается при исчезновении.
- Проверка текстур: `python3 tools/fx_preview_tex.py out.png <тема> <модель>[:side] ...` (отрисовка модели реальным атласом).


## Слой 0.10: «обвязка» навыков (cast_flare, impact_burst, ground_glyph, swing_arc)
Четыре маленьких спрайтовых эффекта (`tools/fx_flourish.py`, подключаются в конце `tools/fx_sprites.py`); у каждого 12 вариантов листа `spr_<id>_<тема>.png`
(тема = цветовая тема `Fx.SCULK … Fx.STEEL`, значение темы выбирает лист). У каждой темы свой знак руны: скалк — вложенные треугольники, кровь — капля, лёд — снежинка,
чума — три пузыря, нечестивость — пентаграмма, дух — спираль, фантом — глаз, огонь душ — пламя, огонь — солнце, золото — восьмиконечная звезда, бездна — волны, сталь — щит-крест.

| Эффект | Где появляется | Анимация (GeckoLib) |
|---|---|---|
| `cast_flare` | правая рука в момент каста (+ пыль) | сбор искр → вспышка-звезда → гаснущее кольцо; плоская руна вращается |
| `impact_burst` | у цели / в точке прицела / на себе (через 1 тик после начала анимации) | 3 кадра расходящихся лучей + кольцо ударной волны на земле |
| `ground_glyph` | под ногами на время действия навыка | две руны вращаются в разные стороны, струи поднимаются вверх |
| `swing_arc` | перед игроком на уровне груди; наклон задаётся для каждого навыка | серп из 3 кадров с поворотом при появлении |

Профили (тема / вспышка / дуга / взрыв / руна) всех 32 навыков — в `fx/FxProfiles.java`; новый навык получает запись одной строкой `MAP.put("id", t(Fx.THEME).flare().glyph(1.0f, 30))`,
иначе `tools/validate.py` сообщит об ошибке. Таймингом управляет анимация игрока: её кадр 0 — момент срабатывания навыка (эффекты мгновенные), поэтому всё стартует с задержкой 0
(взрыв — 1 тик). Выключатель — конфиг `skillFlourish`.


## 3.2.0 — эффекты больше не «сползают»
Эффекты `FOLLOW` и `BEAM` раньше позиционировал сервер раз в тик, а клиент просто телепортировал сущность — отсюда рывки и «сползание». Теперь `SkillFxEntity` синхронизирует id сопровождаемой сущности (`followEntityId`, `beamFromId`, `beamToId`, смещение по Y, флаги align/aim/hand), а `SkillFxRenderer` каждый кадр берёт интерполированную позицию (и поворот) этой сущности. Для игроков масштаб эффекта подгоняется под реальный размер хитбокса (`clamp(bbHeight/1.8, 0.7, 1)`). `Fx.followAim` приклеивает эффект к снаряду по направлению его полёта (кометы `SPIRIT_BOLT`). Луч с `handAnchor` начинается из точки руки, рассчитанной от тела на клиенте (`Fx.handAt`).
