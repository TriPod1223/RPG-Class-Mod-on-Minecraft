# Визуальная идентичность навыков (этап 4 тотального обновления, VFX uniqueness)

Каждый навык опознаётся по трём слоям: выделенный FxType (3D-модель GeckoLib), flourish-подпись
школы (силуэт из `tools/fx_flourish.py`, таблица STYLE) и архетип анимации тела
(`enrich()` в `tools/gen_anims.py`). Два навыка одного класса не должны совпадать по всем трём
слоям одновременно. Пополнение матрицы ниже обязательно при добавлении навыка.

Бенчмарк: Iron's Spells 'n Spellbooks (силуэт частиц на заклинание), Epic Fight (мувсеты с
упреждением и отдачей), Spell Engine (анимации каста по школам магии).

## Что изменено в этом этапе

1. **STYLE (tools/fx_flourish.py)** — все 27 школ получили собственную геометрию flourish-рамки:
   число лучей, форма осколка (`_shard()`: blade / crystal / hook / drop / wisp / spark / wave /
   straight), изгиб дуги swing_arc, число языков ground_glyph, стиль рун
   (tick / diamond / dash / dot / cross). Раньше отличались только палитра и центральный сигил.
   Перегенерировано 113 листов `textures/entity/fx/spr_<fx>_<theme>.png` — имена и раскладка
   прежние, изменения в Java не нужны.
2. **Архетипы анимаций (gen_anims.enrich)** — каждая не-петлевая анимация получила хореографию:
   кадр упреждения (замах, торс против вращения) → авторская поза удара → мягкое приземление.
   Петли (dragon_stance, потоки дыхания/чернил) и референсная поза стойки дракона не трогаются.
   Перегенерированы все 148 JSON в `assets/rpgclasses/player_animation/`.
