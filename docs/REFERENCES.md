# Референсы: Ronova и Curse Spells (3.31)

Разбор двух сторонних модов по просьбе автора. Оба под лицензией **All Rights Reserved**: их текстуры, модели и код в RPG Classes **не копируются**. Мы берём приёмы — композицию, движение, слои, палитры как идею, — и рисуем свои ассеты генераторами из `tools/`. Сами jar-файлы в проект не входят.

## Ronova: Ruler of Death (`ronova` 1.12.3, автор Mian3450)

Мод-персонаж (Ронова из Genshin Impact). 14 способностей:

* багровые луч, сфера и щит;
* «Власть смерти», волна смерти, двойник;
* перья-глаза, взгляд, копьё-глаз, дождь перьев;
* взгляд в царство, прыжок через разлом, своё царство, **Печать** (огромное око в небе).

**Как сделано (приёмы, которые стоит взять):**

| Приём | Как в Ronova | Что берём |
|---|---|---|
| Рисованные текстуры высокого разрешения | 256–2048 px, мягкие градиенты, без пиксель-арта в эффектах | эффекты Эмиссара рисуются кистью-генератором в 512 px (UV модели остаются 128 — приём «HD-текстуры», как у кролика) |
| Своё аддитивное смешивание | собственные шейдеры `fx_add`, `fx_add_premul` | ядра свечения — светлые тона на тёмном, без кубиков; полное аддитивное смешивание — отдельный шаг (свой RenderType) |
| Око из слоёв | веки (верх/низ), жидкая радужка, зрачок-звезда, разрыв, свечение — отдельные текстуры, анимируются по отдельности | «Взор кодекса»: веки раскрываются, радужка вращается, зрачок-звезда пульсирует |
| Пол-витраж | ячейки Вороного с тёмными рёбрами, «стекло», кайма | «Купол безмагии»: яйцо-барьер из багровых ячеек |
| Трещины, расползающиеся по кадрам | `ash_crack_00…29`, сеть трещин растёт | «Отрицание»: волна по земле, за ней расползаются трещины |
| Луч из слоёв | белое ядро, багровая оболочка, кольца, полосы | «Разлом Пустоты»: ядро, оболочка, кольца вдоль луча, рваные края |
| Распад существ | маска растворения из 16 кадров (шум) | позже: распад убитых Эмиссаром в пепел |
| Перья, вороны | меш-перья, вороны | позже: «Крыло пустоты» |

**Палитра:** чёрный, багровый, бело-розовые ядра — почти точная школа Пустоты (`null`). Поэтому Ronova и выбрана референсом для **Эмиссара антимагии**.

## Curse Spells (`cursespells` 1.20.1-1.0.0, автор iriri)

Аддон к Iron's Spells: школа «Проклятие». Около 45 заклинаний:

* проклятые глаз, разрез, рука, взрыв;
* поток душ, адское пламя, столп греха, катастрофа (вихрь);
* небопад, тихий вальс (коса), клинок суда и другие.

Ещё в моде 15 предметов на моделях GeckoLib.

**Приёмы эффектов:**

| Приём | Как в Curse Spells | Что берём для Рыцаря Смерти |
|---|---|---|
| Полумесяц разреза из пламени | `cursed_slash`, `cursed_scar/slash`: светлое ядро, рваный «огненный» край, хвост-язычки | «Ледяное прикосновение» — ледяной разрез со снежинками; «Удар крови» — кровавый разрез с брызгами |
| Столбы душевного огня | `hell_fire/flame_*`: вертикальные языки, кадры | позже: столпы холода (ветка Лёд) |
| Белые сигилы-печати | глаз в круге, мечи, пентаграммы | позже: печати рун Чёрной Кузни |
| Вихрь-воронка | `cosmos/swirl` 2D-спираль | позже: «Чёрный ураган», «Восходящий поток» (Духовный мастер) |
| Луч потока душ | горизонтальный рисованный луч + вспышка у руки | позже: «Лик смерти» |

**Палитра:** голубой душевный огонь — совпадает со школами «Холод» и «Огонь душ».

**Модели предметов (референс для предметов Рыцаря Смерти и Одарённых):**

* **Клинок первого греха** — клинок из позвонков, сегменты с промежутками.
* **Двуручник палача** — светящиеся вставки вдоль лезвия, вынесенные в отдельный слой свечения.
* **Посох еретика** — кольцо-навершие с парящим кристаллом.
* **Неприкасаемая спираль** — древко с осколками, вращающимися вокруг.
* **Книги** — объёмный переплёт с металлическими уголками; у запретного тома цепи крест-накрест.

Общий принцип: предмет — это не «иконка в 3D», а **силуэт + отдельные парящие части + слой свечения + своя анимация покоя** (GeckoLib-предмет). Так и делаем реликвии Одарённых: кристалл в оправе, сфера в гироскопе, книга с уголками, перо, печать, филактерия (по концепт-листу автора).

## План по документу «Изменения в мод» (волны)

1. **3.31 — Рыцарь Смерти, Эмиссар, барьеры.**
   * Новый общий барьер: плоское яйцо-ореол вместо купола из кубиков. Покрывает панцирь Рыцаря Смерти, барьер духов, магический купол Бойца, а заодно барьер Полуголовоногого и эгиду Одарённых.
   * «Ледяное прикосновение» — разрез со снежинками; «Удар крови» — кровавый разрез.
   * Голем нечестивой плоти — объёмная «мясистая» модель.
   * Эмиссар — взор кодекса, разлом, купол безмагии, отрицание в стиле Ronova.
   * Этот документ.
2. **3.32 — Одарённые** (сделано; эффекты Проявлений — отдельной волной).
   * Реликвии — полноценные предметы GeckoLib, как в Thaumcraft, по концепт-листу: кристалл в оправе, печать воли, сфера гармонии, перо памяти, книга знаний, филактерия.
   * Фамильяры — проработанные модели и более умный ИИ.
   * Эффекты Проявлений.
   * Предметы Рыцаря Смерти по референсам Curse Spells.
3. **3.33 — Духовный мастер** (сделано).
   * Щупальца скалка: из ведущей руки, тонкие, извиваются.
   * Скалк-кожа — наросты на игроке.
   * Фантом для «Левитации», 2D-вихрь «Восходящего потока», 2D Z-Z-Z с луной для «Истощения сна».
   * Голубая 3D-ладонь «Удушающей хватки», 2D-пентаграмма «Призрачного молота», 2D «Духовная десятина».
   * Починить «Цепь душ».
4. **3.34 — Боец, Полудракон, Полуголовоногий, Чароборец** (сделано).
   * Полудракон: накопление стихийной силы (урон по вам, убийства, медленнее убывает), удар хвостом и пронзающий хвост без излома туловища, удар хвостом в «Пронзающем хвосте».
   * Полуголовоногий: урон навыков под мобов Майнкрафта, «Телекинетический бросок» держит блок, пока зажата клавиша.
   * Боец: ничего магического вне пути Мистического воина (нет глифов и вспышек), «Вихрь клинков» крутит всё тело, кабан и тяжёлый конь — модели GeckoLib, которые сражаются, «Заклинательный клинок» вкладывает заклинание в оружие один раз, «Залп камней» — блоки, вырванные из земли, «Каменная кожа» видна на игроке, «Сейсмический удар» — удар кулаками и волна по блокам.
   * Чароборец: тентакли — слоты на панели (оружие, инструмент, щит, доп. инвентарь), каждым управляют отдельно.
   * Боец: немагические навыки; анимация «Вихря клинков»; кабан и массивный конь с атакой; «Заклинательный клинок» вкладывает одно заклинание; камни-блоки для «Залпа камней»; каменная кожа; «Сейсмический удар» без пентаграмм.
   * Полудракон: стихийная сила; хвостовые удары без поломки торса.
   * Полуголовоногий: баланс урона под мобов; «Телекинетический бросок» удерживает блок.
   * Чароборец: управляемые тентакли с тремя доп. слотами.
5. **3.35 — Тенеходец** (сделано).
   * «Хватка теней»: рука из аморфной «жидкой тьмы» — лужа чернил, предплечье из неё, суставчатые пальцы с когтями, капли и тяжи чернил.
   * «Кошмар»: модель полностью переделана — колосс из жидкой тьмы (око в груди, рёбра, капюшон с рогами, пасть с клыками, когти, щупальца на спине, капли).
   * «Совет теней»: три рыцаря со своими моделями, анимациями и ИИ (Авангард, Страж, Жнец).
   * «Затмение»: полноценное Чёрное солнце с анимацией, висит над местом применения, не привязано к игроку.
6. **3.36 — Одарённые: эффекты Проявлений** (сделано): у каждого Проявления свой эффект (`tools/fx_gifted.py`, 19 типов `GIFT_*`) вместо общих заглушек.
