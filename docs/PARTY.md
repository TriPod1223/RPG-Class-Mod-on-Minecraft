# Группы (3.16)

Группа — как в ММОРПГ: до 5 игроков (`partyMaxSize`, 2–10). Живёт в памяти сервера: если никого нет онлайн, группа распускается; вышедший игрок остаётся в составе, пока в сети есть хоть один участник.

## Управление
- Вкладка **«Группа»** в журнале (J): создать, пригласить игроков в радиусе 64 блоков, принять/отклонить приглашение, выйти, передать лидерство, исключить.
- Команды (доступны всем): `/party create | invite <игрок> | accept | decline | leave | kick <игрок> | promote <игрок> | list | say <текст>`, `/p <текст>` — чат группы.
- Приглашение приходит в чат с кликабельными **[Принять]** / **[Отклонить]** и действует `partyInviteSeconds` (60 с).
- **HUD группы** — слева по центру: цвет класса, имя (лидер — золотой со звёздочкой), уровень, полоса здоровья; недоступные игроки приглушены.

## Что даёт группа
| Механика | Как работает | Настройка |
|---|---|---|
| Общий опыт | Убийца получает весь опыт класса, каждый другой участник в радиусе — `partyXpShare` (50%) | `partyXpShare`, `partyRange` (48) |
| Убийства для квестов | Убийство засчитывается заданиям фракций всех участников рядом | `partyQuestShare` |
| Нет огня по своим | Урон между участниками (способности тоже) отменяется | `partyFriendlyFire` |
| Разнообразие | +3% урона способностей за каждый ДРУГОЙ класс среди участников рядом | `partySynergyDamage` |
| Ауры классов | см. ниже | `partySynergies` |

### Ауры (действуют на союзников рядом, не на самого носителя)
- **Рыцарь смерти — Знамя рун:** +4% урона способностей союзников.
- **Боец — Авангард:** союзники получают на 6% меньше урона.
- **Магоборец — Аура пустоты:** на 10% меньше урона от магии.
- **Мастер духов — Покров духов:** регенерация раненым союзникам.
- **Полудракон — Тепло дракона:** огнестойкость.
- **Получефалопод — Глубинная связь:** подводное дыхание.
- **Тенеходец — Вуаль сумерек:** скорость в темноте (освещённость < 8).

Все параметры меняются на лету через `/rpg balance` (вкладка «Группы»).
