# Экран баланса для админов (3.16)

`/rpg balance` (оператор, уровень 2+) открывает экран с 44 параметрами баланса в пяти вкладках: **Общее**, **PvP**, **Классы**, **Мир**, **Группы**.

- **[−] / [+]** — шаг значения (с Shift — ×5); **клик по числу** — ввести значение с клавиатуры (Enter — применить, Esc — отмена ввода);
- стрелка **[<]** возвращает значение по умолчанию; у переключателей клик меняет ВКЛ/ВЫКЛ;
- **«Всё по умолчанию»** сбрасывает все параметры;
- изменённые значения подсвечены жёлтым; при наведении на строку — внутренний id, значение по умолчанию и диапазон.

Каждое изменение сразу уходит на сервер (проверка: только операторы), применяется к работающему конфигу и **сохраняется в `config/rpgclasses-common.toml`** — пересборка и перезапуск не нужны, изменения переживают рестарт. Сервер отвечает реальными значениями, поэтому два админа видят правки друг друга. Каждое изменение пишется в лог: `[balance] <ник> set <параметр> = <значение>`.

## Что можно менять
Общие множители (урон способностей, PvP, опыт, лечение, сила выживальных черт, бонус реликвий, макс. уровень, очки модификаций, задержка смены класса), PvP-коэффициенты семи классов, множители урона и регенерации классов (Боец, Тенеходец, Получефалопод, Полудракон, перезарядка рун), мировые переключатели (выживание, диета, высыхание, войны фракций, осады, профессии, Мир Теней) и все настройки групп.

Параметры, которых нет в таблице (списки запретов профессий, ограничения предметов, смещение HUD), по-прежнему меняются в файле конфига.

## Как добавить параметр
1. Объявить его в `RpgConfig` (`defineInRange` / `define`).
2. Добавить строку в `config/Tunables.java` (id, группа, поле, мин, макс, умолчание).
3. Добавить подпись в `tools/party_text.py` (`BALANCE`) и запустить `python3 tools/gen_assets.py`.
`tools/validate.py` сверяет таблицу с `RpgConfig` (имя, поле, диапазон, умолчание) и с файлами перевода.
